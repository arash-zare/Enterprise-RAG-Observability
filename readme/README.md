This directory contains separate documentation for each project phase, explaining its goals, architecture, implementation, and verification steps.
Each phase is documented independently so it can be reviewed and understood before moving on to the next one.


این پوشه حاوی مستندات جداگانه‌ای برای هر یک از مراحل پروژه است که اهداف، معماری، پیاده‌سازی و مراحل راستی‌آزمایی آن را تشریح می‌کند.
مستندسازی هر مرحله به‌صورت مستقل انجام شده است تا پیش از ورود به مرحله بعد، امکان بررسی و درک آن وجود داشته باشد.
